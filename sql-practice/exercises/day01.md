# Day01: 基礎の抽出（SELECT / WHERE / ORDER BY）

1. 全顧客の name と city を表示する。
2. 東京在住の顧客だけを表示する。
3. 価格が3000円以上の商品を、価格の高い順に表示する。
4. カテゴリが「書籍」の商品名を表示する。
5. status が 'completed' の注文の id と ordered_at を、日付の古い順に表示する。
6. 商品を価格の安い順に並べ、上位3件だけ表示する。
7. email に 'example.com' を含む顧客を表示する（LIKE を使う）。
8. 2025-06-01 以降に登録された顧客を表示する。
9. カテゴリが「家電」または「食品」の商品を表示する（IN を使う）。
10. 価格が2000円以上4000円以下の商品を表示する（BETWEEN を使う）。
